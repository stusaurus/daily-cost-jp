# 日用品3カテゴリの購入目的別表示の一本化

## 確認した問題

2026-10-19の公開洗剤ページでは、旧 `.lab-buy-modes` の「単価最安」「普段使い」「まとめ買い」が同一の2,380g×6個を表示していた。単価最安の15%以内という旧選定は、家庭で扱う購入量の区分ではない。一方、既存の数量別枠は380g、1,590g、2,380g×6個を別々に選定していた。

## 変更

- 既存 `step4_recommendations.CATEGORIES` の3カテゴリ（洗濯洗剤・ティッシュ・トイレットペーパー）は、旧価格基準の買い方カードを生成しない。STEP4/5の数量別選定・表示承認・一時停止・鮮度判定をそのまま使う。
- 単価ランキングと価格・数量・送料・楽天リンク・SEOメタデータは変更しない。他カテゴリの旧カードは維持する。
- 数量別枠が無効・未承認・取得失敗・古い場合も、旧カードを代用品として復活させない。確認できない数量区分は既存通り「候補なし」と検索導線を表示する。
- 既存STEP5の旧欄重複診断はレンダラーと同じ選定ポリシーを参照する。廃止済み表示を再現して誤検知することを防ぐ。運営Issue・PR生成器は追加しない。

## 検証

専用テストでは3カテゴリの旧欄非表示、他カテゴリの維持、数量別枠が1つだけで3用途の楽天リンクが異なること、商品URLと金額の一致、無効・未信頼時の非表示、元カタログとランキングリンクの維持を確認する。既存の数量・送料・複数比較単位・商品ID不一致・API失敗テストも継続する。

全体CIとmain公開ビルドの結果はPRおよびIssue #108に記録する。購入クリックや成果報酬の増加は、この表示修正だけでは証明できない。
