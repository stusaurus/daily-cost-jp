# 検索意図から作るページ制作基準（STEP78）

## 方針
検索順位を上げるためだけのテンプレート量産から、検索者が抱える具体的な疑問をそのページで解決できる制作へ変更する。

## 公開前の7つの品質ゲート
1. **具体的な検索意図**：利用者の疑問を一文で定義。GSCと公開競合を確認。推定需要を実測値と混同しない。
2. **独立した解決**：計算・比較・一次データのいずれかで利用者の判断を助ける。商品一覧の言い換えは不可。
3. **再現できる計算**：税込価格、送料、内容量、個数、使用量、計算式を明示。異なる単位を無断で換算しない。
4. **人のための情報**：JavaScriptなしでも目的、計算式、注意点、次の行動が分かる。動かない架空UIは禁止。
5. **発見できる導線**：関連する既存ページから通常のリンクを張り、独立canonicalとサイトマップを生成。インデックス登録リクエストは再送しない。
6. **安全で正確なデータ**：商品安全判定・価格の品質ゲートを緩めず、例示価格を実売価格として扱わない。入力数値は送信・保存しない。
7. **実測で評価**：公開後にURL×自然検索語のGSC表示・クリック・順位を確認。GA4運営者テストや楽天確定売上と混同しない。

## 試験ページ
問い：「洗濯洗剤は1回いくら？ 濃縮タイプやまとめ買いは本当に安い？」
未公開の試験パス：/tools/laundry-cost-per-wash/
2つの製品の税込セット価格、送料、内容量、入り数、ラベル記載の1回使用量を入力すると、1回・月・年の費用と差を計算。
使用量は製品ごとに入力。gとmLは変換しない。架空サンプルは明示。既存の送料込み楽天候補への内部リンクを置く。

## 競合と独自性の限界
2026-11-02時点の公開検索では、単価比較、店頭価格計算、1回洗濯費用計算は既存競合が多い。
本ページの計算式自体を独自技術とは主張しない。送料・セット数量・1回使用量・洗濯頻度・既存比較データ導線を一画面で確認する実用性を検証する。
実際の検索ボリューム、上位表示可能性、差別化の優位性は未確定。

## 横展開の停止条件
単一の試験ページがCI・モバイル・商品品質・リンク監査に合格し、実際の検索需要も確認できるまで、他カテゴリへ自動生成・大量展開しない。
