# STEP9 ティッシュ購入条件の比較

基準：PR #113後の公開カタログ（2026-10-20 06:57 JST）。少量5箱1,050円/180組×5箱、普段20箱6,952円/220組×20箱、まとめ60箱5,299円/200組×60箱。組数の異なる商品であり、同じ商品の節約額ではない。少量候補は既に存在するため、取得不足と誤認しない。

15箱検索は4件全てを数量曖昧・カテゴリー根拠不足・混在セット・種類不適合で除外。その後20箱検索は20件から3件を受け入れたが全てカシミヤ仕様。普段用の検索入口を「ティッシュ 5箱 3個」と比較する。商品名の実際の箱数を解析し、検索語から15箱だと推測しない。5箱/10箱の少量検索、20箱の予備検索、上限4検索/30候補と全品質ゲートを維持する。

既存STEP5未公開比較を再利用し、同じ応答/失敗をメモリ共有して旧15箱系・20箱系と比較。洗剤の過去比較を繰り返さず今回だけティッシュを対象とし、最大5ユニーク検索。箱数・1箱の組数・総組数・枚数の明示根拠・100組価格を匿名receiptへ記録し、不明な仕様を補わない。既存商品名/ID/URLは未公開ビルドの購入リンク検証と本番カタログで照合する。

採否はPRとIssue #108の実測記録で管理する。普段用の購入条件が改善し、少量・まとめ買い・主ランキング・他カテゴリーとPC/スマホの保護機能が維持される場合のみ採用する。購入成果・SEO効果は別途観測。既存のIssue更新抑制は解除しない。
