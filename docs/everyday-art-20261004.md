# Everyday Art / 日用品を、アートにする。

Built-in imagegen created six original scenes: architectural paper columns
(hero), paper rolls, floating tissue, liquid and linen, bathing still life,
and a brush/cloth/steel composition. Common direction: warm ivory plaster,
stone, muted sage/dusty blue, soft upper-left morning light, quiet shadows,
tactile paper/cloth/glass. Surreal sculptural household objects; no brand,
label, price, people or baked-in copy. Generated originals are artwork,
not images or quality claims about any purchasable product.

Production assets: `scripts/design/art/{hero,paper,tissue,wash,care,clean}-*.webp`.
Hero widths 800/1600; other artworks 480/960. Optimized from the generated
originals with WebP quality 80. No image generation required for daily builds.
The source layer copies assets on every regeneration and versions their URLs.
Only the hero loads eagerly/high priority. Every image declares dimensions.

Art → real two-product comparison → life/category entrances → real daily
products → method artwork → working comparison tools → quiet closing artwork.
Mobile separates HTML copy/search from the image to preserve readability.
Category pages keep the immediate factual answer; art is a restrained desktop
header inset. All product and affiliate evidence continues to use actual
Rakuten photographs, prices, quantities and the existing comparison engine.

Prompt set: editorial surreal still-life photography mixed with soft sculpture;
hero is a wide ivory architectural room with blank left half and oversized
paper columns, floating tissue, clear sage liquid bottle and linen on right;
paper is roll columns with an arched sheet; tissue is a delicate floating loop
above a plain tissue box; wash is an unlabelled clear washing bottle with linen
and a water arc; care is a frosted pump bottle, water, stone, towel and foam;
clean is wood brush, white cloth, sage sponge and matte stainless steel.
All share the same palette/light/materials. No logos, lettering, fake product
labels, neon, cartoons or generic emoji. The assets were made with the built-in
imagegen tool and only resized/compressed for responsive delivery.
