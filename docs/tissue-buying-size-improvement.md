# ティッシュ購入量別の導線改善｜5〜10箱の候補とまとめ買い

## 目的

2026年10月10日の公開サイトでは、ティッシュカテゴリの掲載商品の多くが60箱単位。100組あたりの価格比較自体は正しいが、日常的に5箱や10箱だけ買いたい読者にとって支払総額が大きく、選べる量が少なかった。

単純にSEOタイトルやサイトの色を変えるのではなく、既存の100組単価ランキングを維持しながら「必要な箱数から買い方を選ぶ」小さな導線を追加する。

## 仕組み

- ティッシュカテゴリのみ、既存の楽天商品取得を補助する。
- ランキング向けの安全な商品が5件以上でも、箱数と送料込み価格を厳密に判定できた**10箱以下の候補がゼロ**であれば、最大1回「ボックスティッシュ 5箱」で追加検索する。
- 既存の全カテゴリ共通上限5リクエストを超えない。
- 補助検索が失敗しても、既存のランキングはそのまま保持する。
- 結果が10箱以下かどうかは箱数・数量・送料と価格÷単価の一致を共有の品質チェックで再検証する。「5箱×12パック（60箱）」は5箱商品として扱わない。
- 確認済みの少量品があれば、送料込みの**実商品・総額・箱数**と楽天への直接リンクを表示する。商品名から100組単価を一意に確認できた場合だけ参考値も表示する。
- 確認済みの少量品がなければ、価格や商品の存在を捏造せず、サイト内の「ティッシュ 5箱 200組」検索へ誘導する。
- まとめ買いのボタンは既存の100組単価ランキングへスクロールする。既存ランキングの順位・選定・楽天商品リンクは変えない。

## 安全性

少量品は既存の商品フィルタを通過したものだけを公開データへ追加し、生成された楽天リンクについてもデプロイ前に同じ安全チェックを行う。別商品、送料別、可変パックサイズ、数量不一致、無効URLは除外する。

楽天へのクリックは既存のGA4測定属性を利用する。実際の売上・成約件数の取得にはつながらず、クリックが売上になるとは断定しない。

毎日更新される実データにより、少量の候補が表示される日と「該当候補なし」の日があり得る。楽天市場全体の最安値とは表示しない。

## 検証

- 単体テストで5箱・10箱・60箱の取り違え、送料、可変数量、無効URL、任意のAPI呼び出し失敗を検査。
- GitHubの既存PR全サイト生成・商品品質検査、PC・390px・320px検索／購入導線とLighthouseで回帰確認。
- 検証成功まではmainにマージしない。
- マージ後に公開ティッシュページで「少量」リンクまたは安全な代替案が実際に表示されているか確認する。商品が取得できたかどうかは推測しない。

## サイトの本来の価値

「最安値」という表示を強くするより、**欲しい数量と支払総額を選べる**ことを優先。高額なケース販売だけを推奨しない、実生活に役立つ比較サイトを目指す。
