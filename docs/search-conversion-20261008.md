# 検索流入3カテゴリの購入判断改善（2026-10-08）

対象：`/categories/laundry/`、`/categories/tissue/`、`/categories/toilet-paper/`。
指定されたSearch Console期間は2026-09-08〜2026-10-06。優先順位は洗剤132表示／13.2位、ティッシュ130表示／12.6位、トイレットペーパー92表示／11.9位。

## 監査と修正

検索意図に沿ったtitle/H1/description、正規URL、比較FAQは既存処理に実装済みのため維持。問題は購入判断の冒頭回答で、カテゴリ共通単位を使った集計や単一候補が、洗剤の重量・容量、トイレットペーパーの重ね数・長さの差を十分に伝えられない点だった。

`improve_purchase_pages.py` の価格回答を、共有品質フィルターを通過し、`comparison_unit` で条件を確認できる商品だけに限定した。

- ティッシュ：商品名で組数を確認できた100組単価。
- トイレットペーパー：シングル10m・ダブル10mを別々に集計。長さ・重ね数が不明なら価格回答の候補に使わない。
- 洗剤：100g・100mlなどを別々に集計。使用量・銘柄・濃縮度が違えば単価だけで買い先を決めない。

各条件で掲載候補の最低単価、中央値、候補数を表示。中央値未満という相対的な目安を示し、市場全体の最安値や相場とは明確に区別する。該当商品の商品名・販売数量・ショップ・送料込み支払総額と、商品カードへのリンク、同じ商品の楽天購入確認リンクを掲載。クーポン・ポイント、地域別送料、在庫は購入前に確認する。

イラスト、配色、既存商品カード、正規化した比較表、検索・保存・比較、楽天API、Worker、品質判定、X投稿、定期更新、Pagesを維持。生成HTMLの一時修正ではなく既存生成スクリプトを変更。sitemap.xml・robots.txtの生成処理、Search Console設定は変更していない。

## GA4の実取得と区分

Windsor.aiの接続済みGA4プロパティ552907444から指定期間を取得。`event_name=affiliate_click`、`page_location`、`customevent_operator_test`、`event_count`で分類した。

|対象|operator_test=1|判定不明|operator_test=0|計|
|---|---:|---:|---:|---:|
|stusaurus.github.io/daily-cost-jp/ 本番URL|35|16|3|54|
|その他のサイト|11|1|1|13|
|全体|46|17|4|67|

取得したaffiliate_clickにはlocalhostの行はなかった。プロパティの他イベントに開発アクセスが混在することを否定する結果ではない。operator_test=0も人間の購入者である証明ではなく、非テストフラグのクリックという意味。判定不明を実ユーザーの成果に含めず、楽天クリックを購入・売上として扱わない。

今後のイベントには `site_id=daily-cost-jp`、`traffic_environment=production/development`、実際の`page_path`と`page_location`を明示。既存のoperator_testとconversion_sourceを維持。ローカル・他サイトの混入を防ぐため、レポートは本番ホストと`/daily-cost-jp/`パスの両方で絞る。CSV集計には `scripts/report_daily_clicks.py` を使用できる。列はeventName,pageLocation,operator_test,eventCount。URL欠落はunscopedに分け、0に補完しない。
