# 洗剤の現行規格を使った少量検索の未公開比較

## 仮説と最小変更

2026-10-20の公開カタログでは400g系・900g系とも少量の追加候補0件。花王の公式Q&Aには2026-07-14発売のアタック抗菌EXつめかえ850gが掲載されている。
https://www.kao.com/jp/qa/detail/42136/

400g検索を850g検索へ置換し、900gの既存フォールバックを維持する案を検証する。検索語は供給候補を探す入口にすぎず、商品名から実際の総数量を解析し、少量帯・送料込み・商品ID/URL・比較単位・全体外れ値の既存検査をすべて通す。850gというキーワードから数量や同一商品を推測しない。通常のMAX_REQUESTS=4/MAX_CANDIDATES=30、他カテゴリ・主ランキング・推薦器は変更しない。

## 比較方法

既存STEP5の未公開実商品検証でのみ、洗剤の旧検索条件も実行する。同じキーワードの応答をメモリ内で再利用し、旧/新それぞれ最大4検索、ユニークな洗剤検索は最大5種類。API失敗も共有し、再取得や0件への変換をしない。比較用の旧検索は本番ビルドでは呼ばない。新しいworkflowや監視系統は追加しない。

既存artifactに匿名の数量・支払総額・比較単位・spec_refと取得診断を保存し、候補の商品名・URL・認証値を比較レポートへ追加しない。API失敗があれば比較UNKNOWN。少量の総額低下だけでなく、他2用途の選定維持・ランキング不変・実商品品質・PC/スマホ保護機能も確認して採否を決める。別ブランド・別仕様の比較であり、同一商品の節約額や売上効果は証明しない。

実商品検証の結果が未取得の段階では未採用。結果と採否はPRとIssue #108へ記録する。
