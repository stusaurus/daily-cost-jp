## 証拠の経路と安全境界

1. 既存の公式Google OIDCで取得済みの aggregate / discovery artifactをGitHubから読む。
2. main / 正しいworkflowパス / 成功イベント / リポジトリ / SHA形式 / run ID / artifact所属を確認。
3. source識別、6組の名前とURL-prefix property、基準日から導出した全期間を照合。
4. run日時とGSC基準日の両方が10日以内（未来は拒否）。不明・古い・403/429・欠落はUNKNOWN。
5. 直近10runまで、別基準日最大2件。ZIP 2MB・JSON 1MB上限。展開せず許可メンバーのみ読む。
6. 元SHA/run/artifact/期間を保存。今日のmainと同一SHAであるとは主張しない（日次商品更新と週次測定は別）。

Google APIリクエスト・権限・秘密鍵は追加しない。PRにGoogle認証を渡さない。
GitHubのartifact転送時は既存のリダイレクト処理でAuthorizationを除去する。
運営artifact/Issueに再掲するのは集計・固定の候補コード・出典だけ。検索語そのものや商品名、確定報酬は再掲しない。
