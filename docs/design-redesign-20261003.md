# 日用品コスパ比較：暮らしの価格研究所

## 設計

旧画面は説明・検索・判定ツールが先行し、写真が小さく、総額・箱単価・正規化単価の優先順位が曖昧だった。正規化計算、数量判定、商品品質、保存・比較、価格履歴、SEO URL、GA4、楽天導線は維持する。

新しい構成は、実商品で総額と同量単価の逆転を見せるファーストビュー、暮らしから探す、21カテゴリ、今日の実商品5候補、比較の仕組み、保存・店頭比較・検索ツール。ホームの全商品データは折りたたみで維持。商品カードは写真、商品名、正規化単価、数量、送料込み総額、楽天リンクの順。カテゴリの詳細比較表もデータ・アンカーを維持。

生成り、深い青緑、紙面のような罫線、数字のセリフ体を用い、安売りの赤や大量の絵文字、グラデーション、装飾イラストを使わない。外部フォント・画像生成・UIライブラリの読み込みなし。既存の楽天商品写真を使用する。

600px以下は写真と情報を分けた1列カード。下部カテゴリ・今日の候補・保存/比較ナビ、44px以上のタップ領域、safe-area、折り返し、表内スクロール、キーボードフォーカス、動きを減らす設定へ対応する。

## 実装・品質維持

`redesign_laboratory.py`を共通ビルドのGA4注入前へ追加。旧CSSを置き換え、内容の取得・計算を変更せず、JSON-LD・canonical・title・description・ID・楽天URL・機能スクリプトを維持。BeautifulSoupのバージョンは固定し、PR/本番の両方でインストールする。画像の拡大要求は既存の楽天サムネイルホストだけに適用し、表示領域を予約する。

選択比較に実データ上の総額と単価の逆転説明、商品写真、閉じる操作、結果へ移動を追加。既存保存キー、イベント名、conversion_sourceは維持する。

ローカル回帰：Python93件・JavaScript31件。生成済み3画面のインライン機能スクリプトをDOMテストし、保存/比較と楽天クリック発生元を確認する処理も公開前ゲートに追加。sitemap/robots/canonical/JSON-LD/商品品質ゲートは維持。公開画像・実ブラウザ確認は公開後に実施する。ローカルファイルのクラウドブラウザ表示はURLポリシーで禁止されているため使用しない。
