# ティッシュ普段用の再調査（2026-10-20）

PR114の「ティッシュ 5箱 3個」は9件すべて不採用で、少量5箱1050円/普段20箱6952円/まとめ60箱5299円の最終選定は変わらず不採用とした。

今回は旧「ボックスティッシュ 15箱」から語を一つ減らした「ティッシュ 15箱」を未公開で比較する。箱ティッシュのカテゴリー判定は維持し、ソフトパックや曖昧な数量を表示件数のために許可しない。20箱の予備検索、5/10箱の少量検索、通常上限4検索/30候補、個別/プールの全品質ゲートを維持する。

既存STEP5比較の同一応答キャッシュを使い、最大5ユニーク検索で比較。過去の洗剤比較は再実行しない。検索語は固定の商品検索語のみでGSC/ユーザー検索語ではない。商品名/商品ID/価格/送料flag/公開商品URL/店舗名だけを明示allowlistで保存し、数量の解析結果・個別ゲート理由を既存artifactへ追記。秘密/応答全体/エラー本文は保存しない。個別証拠はプール外れ値・用途判定前の段階と明記し最終採用と混同しない。

実APIと画面の結果はPR・Issue108へ記録。少量・まとめ・主ランキング・他カテゴリーを維持し、普段用の購入条件が安全に改善した場合だけ本番へ採用する。改善しなければ既存検索を維持する。異なる商品の差は同一商品の値下げ/節約額ではなく、購入/収益効果は未測定。
