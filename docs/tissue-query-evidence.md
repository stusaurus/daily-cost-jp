# ティッシュ普段用の再調査（2026-10-20）

PR114の「ティッシュ 5箱 3個」は9件すべて不採用で、少量5箱1050円/普段20箱6952円/まとめ60箱5299円の最終選定は変わらず不採用とした。

最初に「ティッシュ 15箱」を未公開比較したが5件全て不採用。数量選択・ティッシュケース・保湿品・ポリ袋等で、普段用の通常仕様は返らなかった（run39389614773）。検索語の緩和は採用しない。

次にレビュー限定のみ外す比較（run39390677106）では15箱/20箱が各30件返ったが、カテゴリー不適合等で普段枠が空になったため、そのままの変更は不採用。

その原本にエリエール「360枚(180組)×5個パック×3セット 合計15箱」（netking:10003583、3382円、送料flag0、レビュー0）を確認。販売店ページ https://item.rakuten.co.jp/netking/or-13619-3/ も15箱・180組・3382円を明記。旧コードは「ティシュー」の表記と複合数量を認識できなかった。

最終案は5個×3セット=明記合計15箱を相互検算し、個/セット/箱に追加・矛盾・選択表記がなく、ティシュー・組数・箱総数の明示が揃う場合だけ既存のbox単位として解析する。ブランドから種類・組数は推測しない。他カテゴリーの数量解析は不変。ティッシュ普段用の最初の15箱検索だけレビューなしも対象とし、20箱の予備検索は従来のレビューあり条件を保持して安全な旧候補への復帰を維持する。ランキング・少量・他カテゴリーの取得条件は不変。通常上限4検索/30候補、送料/購入先/外れ値/用途等の判定と閾値は維持。

保存済み実API応答のオフライン再生では、普段用が20箱6952円から15箱3382円（180組×15=2700組、100組125.26円）へ変化。少量5箱1050円とまとめ60箱5299円は同一。最終headのCIと本番の再取得で再確認するまで検証済みとしない。沖縄・離島への配送不可は商品名から削除しない。

既存STEP5比較の応答キャッシュはレビュー条件もキーに含め、異なるリクエストを混在させない。少量の応答を共用して最大5ユニーク検索で比較。過去の洗剤比較は再実行しない。検索語は固定の商品検索語のみでGSC/ユーザー検索語ではない。商品名/商品ID/価格/送料flag/公開商品URL/店舗名/レビュー件数を明示allowlistで保存し、数量の解析結果・個別ゲート理由を既存artifactへ追記。秘密/応答全体/エラー本文は保存しない。個別証拠はプール外れ値・用途判定前の段階と明記し最終採用と混同しない。

実APIと画面の結果はPR・Issue108へ記録。少量・まとめ・主ランキング・他カテゴリーを維持し、普段用の購入条件が安全に改善した場合だけ本番へ採用する。改善しなければ既存検索を維持する。異なる商品の差は同一商品の値下げ/節約額ではなく、購入/収益効果は未測定。
