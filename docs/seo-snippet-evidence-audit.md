# Search Console検索結果と実画面SEO設定の自動照合

## 2026年10月10日時点の観測

対象：日用品コスパ比較の主要3カテゴリ（洗濯洗剤・ティッシュ・トイレットペーパー）。Search Console直近28日（9/10〜10/7）の実績は以下。

| カテゴリ | 検索表示 | 検索クリック | CTR | 平均順位 |
|---|---:|---:|---:|---:|
| 洗濯洗剤 | 117 | 2 | 約1.71% | 13.32 |
| ティッシュ | 124 | 2 | 約1.61% | 12.02 |
| トイレットペーパー | 81 | 1 | 約1.23% | 12.36 |

Search Consoleの公開用レポートでは、28日で20表示以上という安全なフィルタを満たす検索クエリ行が**0件**だった。ただし、**実際の検索が0種類という意味ではない**。プライバシー処理・上位行制限に加えて、レポート設計で少数検索語を除いている。

現在の公開ページのtitle/H1/導入文とソース内設定を確認したところ、すでに「どこが安い」「送料込み」「単価比較」などの検索意図に沿った文言がある。具体的な高頻度検索語が見えない中で、タイトルを安易に改変して既存の検索順位を損なうのは避ける。

## 今回追加すること

既存のGA4・Search Console統合レポートとChromiumのPC/スマホ監査に、実公開ページのSEO設定を加える。

- HTMLのtitle、meta description、canonical URL、robots/noindex、H1テキストを実画面から抽出する。
- title未設定やnoindex誤設定は重大な技術的問題として報告。
- description未設定やcanonical不一致は手動確認を要する警告として報告。
- Search Consoleのページ別調査候補（titleの訴求を調べる等）を画面のSEOメタ情報と並べて表示。
- 公開可能な検索クエリ数と証拠不足を統合レポートに明記。
- データが不足する間、**SEOタイトル・説明文の自動変更を一切行わない**。
- 15画面までのChromium表示監査と楽天CTA安全検証を引き続き維持する。監査は楽天のURLをクリックしない。

## 自動判定と実装の線引き

- GSC検索表示数／クリック／平均順位はGoogle検索の指標。
- GA4ページ表示数／楽天クリックは別データであり、検索ユーザーが楽天を押したとは推測しない。
- CTRが低いことだけではmeta description・titleの欠陥を証明できない。順位、検索結果の競合、検索語との一致、サンプルサイズを併せて見る。
- 計測不足なら改変せず観察を継続。技術的に異常があっても自動修正は行わず、実画面・差分・QAで再現を確認する。
- 閲覧専用のGitHub Actions・Googleスコープを維持。商品データ・送料込み価格・容量判定・楽天アフィリエイトID・サイトの自動公開は対象外。

## 検査の見方

GitHub Actions → GA4 Three-Day Read-Only Analysis → Read-only production browser CTA audit → Summaryの「検索結果向けメタ情報」。JSONはga4-live-cta-qa成果物に保存。

次回以降、十分な検索語と流入傾向が揃えば、現状メタと検索クエリの一致を確認した上で個別に小さな改善PRを作る。その際も前後比較には少なくとも複数週間を要し、効果を保証しない。
