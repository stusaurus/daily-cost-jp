# 上質な暮らしを、数字で賢く選ぶ

## 公開画面の評価

前回の生成り・罫線・実データ比較は維持する。現状では比較見本の白い枠、同じ箱状の商品カード、10〜12px中心の補足文字、カテゴリ一覧の絵文字、写真への色合成が、静かな上質感と可読性を弱めていた。数字と単位の区切りもページによって異なっていた。

## 今回の変更

温かいアイボリー、チャコール、限定した深いセージへ調整。カードの外枠を減らし、写真の展示面・罫線・整列で売場を構成する。比較単価は大きな数字、小さな通貨、別行の単位を共通部品として生成。表示値・比較単位は既存計算の結果をそのまま使う。

トップの実商品2件には正規化前後の価格と事実としての単価差を表示する。「低い単価」は表示された同じ単位の2商品の比較に限定し、市場全体の最安と表現しない。カテゴリ一覧・暮らしの入口は掲載中の実商品の写真から生成し、写真はカテゴリの商品例であることを示す。架空商品や別カテゴリを作らない。

商品名は全文をDOMとtitleへ保持し、カードでは行数を制限する。数量・総額・送料・販売店・価格履歴・購入条件は削除しない。CTAは余白と輪郭で押せることを示す。モバイルでは14pxの商品名、42pxの単価、44px以上の操作領域を基本とし、320px付近では数字が収まる配置へ調整する。

/today/は「今日、比べておきたい日用品」という編集ページへ。巨大な順位番号を見せず、中央値比較の意味と注意書きを維持する。保存・比較は既存実装とキーを維持。SEO title・description・canonical・JSON-LD・URL、GA4、楽天リンク、Worker、取得・品質監視は変更しない。自動生成の共通プレゼンテーション層だけを修正する。

PRのLighthouseは実データから生成したトップPC/モバイル、ティッシュモバイル、today PC/モバイル、カテゴリ一覧PCを記録する。テスト用operator_test=1の表示とCI環境が性能測定へ影響するため、公開利用者のCore Web Vitalsと同一視しない。公開後はHTTP・SEO・現在データとの一致とブラウザの表示・操作を再確認する。
